# 肘关节控制与持球抬臂研究计划

已完成单关节闭环模拟、11 个工况的 C++ 对照、固定接触筛查、虚拟张力反馈和结构候选件对比。表中保留原设计问题与验收方法。双指动态接触迁移、真实软垫参数和硬件验证仍待研究。[实验结果和复算入口](controls-and-grasp.md)

| 顺序 | 工程问题 | 实施与验收 |
|---|---|---|
| 1 | 同一收绳量为何得到不同指形？ | 整理机械手原、新弹簧在同一输入下的对比图，配 240 步接近曲线。分别标记拇指和食指首次接触，注明五指空手视频为装配演示。 |
| 2 | 肘部在负载变化时能否跟踪指令？ | 使用 R2 的质量、重心和转动惯量。对同一 90°、1.2 s 轨迹，在相同采样、增益、力矩限幅及驱动滞后下比较 PD、PD 加重力补偿。建立目标角、仿真角和施加力矩的同步日志。水平无摩擦静平衡对照现有力矩解。 |
| 3 | 控制器在何处失效？ | 以 0、150、300 g 作为对象负载，分别运行已知负载、名义负载失配和有限时长外扰。记录角度均方根误差、最大误差、末端保持误差、恢复时间和饱和时间占比。预先记录误差带与恢复判据，减半求解步长检查指标。执行器滞后、摩擦和力矩限制均标明来源或假设，不由额定输出反推零速热持续能力。 |
| 4 | 手拿球抬到什么角度仍能保持？ | 以装配坐标转换重力，将负载置于真实球心并更新持球构型质量分布。在七个肘角求准静态接触平衡并复查局部稳定性，再加密状态变化的区间。分别报告接触状态、摩擦需求和稳定性。对点接触模型中无法平衡的力矩直接记录不可行。 |
| 5 | 遇到负载或轻微滑移如何调整？ | 先建立可观测的传感模型，区分模拟真值、模拟读数与控制器估计值。对比固定收绳与受张力上限约束的反馈调节。动态抬臂另计球心线加速度等惯性效应，准静态结果单列。 |
| 6 | 下一处结构修改值得吗？ | 在同一载荷和测点下对比固定支架与运动侧转接件的候选改动，报告增重和下沉贡献变化；将运动侧增重带回力矩与跟踪工况复算。 |

公开交付贯穿各阶段。在线 Notebook 复用计算函数，持续集成运行回归测试。各工况提供输入、原始日志、指标和生成图的命令。供评审的硬件资料保持既定授权范围。

岗位参考包括海康机器人的机械臂运动控制岗、Apptronik 的执行器控制岗及 Boston Dynamics 的 Spot 操作岗。分别用于对照控制性能评价、执行器建模和接触力控能力。纯仿真在项目记录中标明，台架辨识与实机部署单列为后续经验。
