# 从目标接触点反查六路腱驱能否抓起球

**33 g、Ø20 mm 球在下垂阶段就掉落了。** 本轮从张开收绳，在同一球心比较预设收绳、三指法向力反馈、食指弹簧刚度对调。每组各用 0.25 ms 和 0.125 ms 积分步长。撤支撑时六次均只有拇指测到有效指腹压力。从撤支撑到水平保持结束，以 2 ms 采样，六次都没有记录到三指同时超过 0.01 N。前一版凹面指腹的掉球结果保留作历史对照。[历史对照](tripod-coordination.md)

## 目标与模型

掌心在抬平时朝下。33 g 球静止需要三指合计向上提供 0.324 N，并平衡绕球心的力矩。先前固定接触计算给出的三点位置用于本次取球目标。以掌坐标系中的三个接触法向为目标，食指、拇指、中指组成三角形，三个候选指腹采用 9.2 mm 半径的球面。拇指增量横摆 −5.282°，中指在原 15° 档上再加 −0.920° 的带符号修正，均于取球前锁定。摩擦系数假设为 0.28。这组改动是仿真候选几何。[目标点、方向及关节角](../examples/inverse-release/target-contacts.csv)

六路机构沿用原分工。三根工作指各使用一根主动屈曲腱，指节角由绳力、复位弹簧和碰撞共同求出。选用预设行程 19.87、9.90、27.94 mm，分别由三指目标关节角对应的几何收绳量加 0.10 mm 得到。反馈组沿用 500 Hz 模拟压力反馈，三指各以 1.2 N 为目标。弹簧组仅对调食指近侧指间关节与远侧指间关节的刚度，从 0.01505 / 0.00580 变为 0.00580 / 0.01505 N·m/rad。未叠加反馈。

球在取球阶段由数值夹具定位。撤除后球有六个自由度，各指腹接触可形成、滚动或分离。下垂等待 1 s 后开始 1.2 s 五次多项式抬臂，再水平保持 2 s。动态计算保留登记的手部碰撞凸包。硬件反力来自近似碰撞几何。[模型参数](../examples/inverse-release/setup.json) · [MuJoCo 接触模型](https://mujoco.readthedocs.io/en/stable/computation/index.html#contact)

## 哪根手指先出了问题

下表为 0.125 ms 步长。间隙为撤支撑时球与指腹两球面间的几何距离，触地为撤支撑至接球平面首次产生大于 0.001 N 反力的时间。

| 配置 | 食指间隙 | 中指间隙 | 拇指法向力 | 拇指法向偏离目标 | 球触地 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 预设收绳 | 17.87 mm | <0.001 mm | 0.105 N | 0.36° | 0.470 s |
| 三指反馈 | 6.40 mm | 2.15 mm | 0.164 N | 9.19° | 0.474 s |
| 仅对调食指弹簧 | 0.99 mm | <0.001 mm | 0.105 N | 0.36° | 0.454 s |

预设收绳时，食指从根到尖的目标角是 53.4°、53.8°、32.3°，实际为 46.7°、18.5°、71.6°。末节卷得过多，中节屈曲不足。对调弹簧使对应角变为 40.6°、70.7°、26.6°。食指到球的距离明显缩短，正向预压力仍未建立。中指在两个配置下几何上非常接近球，但两种步长均未记录到有效的释放瞬间压力。三指力反馈让食指靠近，同时增大了中指间隙和拇指法向偏角。三组改变均未通过 33 g，150 g 未试。

下一项设计检查应同时施加位置、接触法向和可建立的预紧力约束，逆算食指各关节刚度及三指行程，在支撑尚未撤去时先检查三个球面接触的受力。单独缩短指腹与球面的距离不足以验收。弹簧对调工况的碰撞模型还记录到食指与中指轴端防脱件约 0.45 N 的峰值接触，修改实体前应复核其实际间隙。
