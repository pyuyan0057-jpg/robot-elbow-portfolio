# 从三指预紧力反算弹簧与收绳行程

33 g、Ø20 mm 球在撤去定位支撑的一刻有了三处指腹压力。筛出的三组候选在两种积分步长下都于 **6 ms** 首次失去中指有效接触。下垂保持 1 s 结束时球已由指节硬件承托。按先持稳再抬臂的顺序，本轮停在 33 g 下垂试验。原六路驱动、取球位置、球面指腹、锁定横摆角和对照记录保留。[上一轮掉球对照](inverse-release.md)

## 怎样从球反推到弹簧

在下垂姿态，三处接触力之和应向上抵消 0.32362 N 重力，绕球心的合力矩应为零。用目标姿态下的 MuJoCo 接触点雅可比把每根指腹的作用力投影到各个关节。每指只允许一个共同腱张力，每个关节仍可独立转动。由虚功，静态时第 j 个关节应满足

```text
T r_j(q) = k_j q_j + 0.002 N·m + 重力补偿力矩_j + (Jᵀ f)_j
收绳行程 = 当前姿态的几何缩绳量 + T / (10,000 N/m)
```

f 是指腹作用在球上的力。食指三个刚度和三根工作腱的张力为设计变量，拇指和中指弹簧沿用前值。限制力处于摩擦系数 0.28 的内接 32 边形摩擦锥内，单腱张力上限 25 N，法向力上限 2.2 N，食指各关节刚度范围假设为 0.002–0.12 N·m/rad。搜索先满足球的六项平衡和食指三个关节平衡，再最小化拇指及中指未平衡的最大关节力矩。改变共同腱的张力余量可得到多组食指刚度。此方法采用了欠驱动夹爪按关节耦合和接触力共同评价的思路。[反算代码](../preload_design.py) · [Dollar 与 Howe 的研究](https://www.eng.yale.edu/grablab/pubs/dollar_ijrr2011.pdf)

另将法向力下限放宽到 0.01 N，使用外切 32 边形放宽摩擦锥，最优时仍至少有一个拇指或中指关节差 **3.53 N·mm** 才能平衡。该界限只适用于所指定的三个接触位置、关节姿态和上述参数范围。三根手指弯到别处时须重新计算。[放宽约束后的结果](../examples/preload-design/outer-bound.json)

## 从张开开始验证

三档预紧力下限（0.2 / 0.5 / 1.0 N）各取三档食指腱余量（0.5 / 2 / 3 N），先试九组反算值，再对选中刚度做 18 组额外收绳和 64 组三指独立增减行程。91 组均从原取球准备姿态开始，三根工作指从张开收绳；支撑瞬时撤除后先观察 0.14 s。按连续有效时间、累计有效时间、释放瞬间最弱指压力、间隙排序。前三组各以 0.25 和 0.125 ms 积分步长复算下垂 1 s，每 2 ms 记录一次。有效保持要求三个工作指各超过 0.01 N，无名指不超过 0.001 N，指节硬件及接球平面均不承托球，峰值张力不超过 25 N；末 0.25 s 球相对掌速度低于 2 mm/s、角速度低于 0.2 rad/s，肘角误差低于 1°。[筛选与分级验收代码](../preload_trial.py) · [结果与时间序列](../examples/preload-design)

## 代表候选 fine48

食指从指根到指尖的三个关节反算刚度依次为 **0.02272、0.03326、0.07424 N·m/rad**。精细步长的实际求解如下。

| 工作指 | 反算目标法向力 | 反算行程 | 细扫后行程 | 撤支撑时实际法向力 |
| --- | ---: | ---: | ---: | ---: |
| 食指 | 0.671 N | 20.473 mm | 22.100 mm | 1.947 N |
| 拇指 | 0.500 N | 10.079 mm | 11.332 mm | 0.722 N |
| 中指 | 0.500 N | 27.893 mm | 26.416 mm | 0.534 N |

按求解姿态重建三处实际接触法向，在实际法向力下，若要使球的合力为零，沿所缺合力方向需要 1.519 N 的切向力投影，三处接触合计最多提供 0.468 N。即使允许所有指腹摩擦都充分发挥，也无法平衡释放瞬间的球。中指在 6 ms 的采样点首先低于有效阈值，30 ms 时硬件首次接触球。1 s 时球相对手掌移动 37.36 mm，食指和中指的硬件合计承托球（记录的接触法向力之和为 0.424 N）。球未触及接球平面。这一结果把“碰到球”和“三指独立夹稳球”区分开来。[释放瞬间受力审计](../examples/preload-design/release-audit.json) · [各工况下垂验收](../examples/preload-design/hang.jsonl)

若继续保留六路驱动，下一项值得验证的改动是拇指和中指近、远关节的被动力矩分配，例如在反算中加入它们的腱绳导向力臂，再用相同目标接触点检查上述剩余力矩能否降为零。通过后才值得修改实体。以上刚度与行程是仿真设计参数。
