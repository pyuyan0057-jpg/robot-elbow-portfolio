# 七轴机械臂 · 把自由球送到指定触点

[C8 对照版本](https://github.com/pyuyan0057-jpg/robot-elbow-portfolio/commit/7605f69)保留了修改前的抓放记录。对象是直径 40 mm、质量 33 g 的自由球。机械臂有七个关节，手部使用原有六路驱动。球从桌面拿起、抬升、保持，再下降。评价结束在球第一次碰桌。

## 实际复测结果

通过要求同时满足持球至下降触桌和水平落点偏差不超过 2 mm。右列按每个 2 ms 样本都有手部接触力复核。

| 工况 | 0.30 通过 | 0.45 通过 | 0.45 持球到触桌 | 0.45 严格接触且达标 |
|---|---:|---:|---:|---:|
| 原 14 组 | 14/14 | 14/14 | 14/14 | 11/14 |
| 扩展方向，2.5 / 5 N | 7/20 | 10/20 | 11/20 | 8/20 |
| 单独留出的斜推，0.6 / 2.5 / 5 N | 10/24 | 13/24 | 13/24 | 13/24 |
| 26 方向 × 三个阶段，0.60 N | 53/78 | 61/78 | 61/78 | 61/78 |
| 同一 26 方向 × 三个阶段，0.10 N | 78/78 | 78/78 | 78/78 | 78/78 |

同一动作在 0.45 下修复了独立组中三次掉球。举例，2.5 N 的斜向推力作用在下降初期时，原球脱手，新系数下首次触桌偏差 0.83 mm。其他方向即使只有 0.6 N，也仍会脱手。在独立 24 组里分别设为 0.60 和 0.90 后，均为 14/24 通过。此处为仿真材料参数灵敏度分析。

0.45 时三组原侧推的首次触桌偏差分别为 0.80、0.81、0.81 mm，各有一个 2 ms 样本的手部接触力低于 0.001 N。0.30 下原试验为 14/14 达到工程标准，严格标准为 12/14。在保留球位和噪声并撤掉扰动力的独立组中，0.30 为 24/24 达标。

0.45 的物理步长从 0.25 ms 减到 0.125 ms，重新从桌面静止状态复跑三组，控制周期保持 2 ms。结果见[减半步长记录](evidence/half_045.json)。

## 原来从哪里掉

用 C8 同样的球位、外力及触觉噪声重跑三组侧推，44 列原始日志与对照一致。在随手移动的掌坐标中，球受推期间沿横向往食指侧移动约 21 mm，并伴随约 93°～95° 的累计相对转动。随后球改向小指和腕部一侧。下降中失持的三个时刻分别是 5.558、5.820、5.604 s。当时最接近球并分列出口两侧的是拇指和小指，中指与球已相隔约 1.2～1.5 mm。三次均从拇指和小指这一侧逸出。球的平移和转动都有记录，接触处纯滚动与滑动的比例未测定。[实际表面间距与出口方向](evidence/escape.json)

## 手怎么改

- 桌面初抓时，食指在原指令上短暂增加 0.60 mm 的收绳。抬升时小指比其他手指提前 120 ms 开始保护性收绳。相对原参考行程，食指 −1.17、拇指 +0.29、中指 +1.39、无名指 0、小指 +6.17 mm，拇指对掌参考角微调 −1.60°。这些量是腱绳参考值，实际关节位置由受力求解。保留原有触觉反馈和传动力上限，小指在仿真中能达到已有的 25 N 上限。
- 接近桌面时，根据已知球半径和拇指、中指、小指的关节位置，估计球心相对手掌的位置，再由七轴手臂小幅修正水平落点。控制器使用编码器、原有虚拟触觉和桌面支撑信号。求解器中球心的真值用于评分。
- 另一轮试验把同一高位抓姿分别向六个方向推，比较了 800 组位置指令，并另试了 125 组放开无名指的设置。按方向筛出的三个候选回到真实拾取、抬升与下降全过程后，各自只通过选定的 8 组中的 3 组；当前版本通过其中 4 组，因此保留当前动作。[筛选与复跑对照](evidence/screen_review.json)

## 怎么算通过

首次触桌取抬离桌面后，球桌法向力首次超过 0.03 N 的 2 ms 记录。球心水平投影与桌面目标的距离须不超过 2 mm。按与 C8 可比的工程判据，五指合计球接触载荷连续 40 ms 低于 0.015 N 记为失持，并要求触桌发生在下降阶段。另记录一个更严格的指标，自离桌至触桌，每个 2 ms 样本都要有超过 0.001 N 的手部接触力。严格指标同样要求落点达标。离散采样分辨不了两个样本之间更短的接触变化。

## 泛化验证

原 14 组保留固定的初始位置、噪声、扰动力和时刻。扩展 20 组覆盖正负坐标轴和斜向，峰值 2.5 或 5 N。最后另留 24 组，覆盖八个象限内的随机斜向、0.6 / 2.5 / 5 N 三档、变化的初始球位和扰动时刻。26 方向面板另在每个方向分别测试抬升、高位、下降三个阶段，共 78 组。每次都从桌面静止状态重新积分。球体、手套、噪声与控制参数在同一对照内一致。世界坐标 +Y 朝下，桌面为 XZ 平面。0.6 N 方向面板的推力为峰值，持续 180 ms，按正弦平方加载。轻推面板为同组参数的 0.10 N 版本。

## 为什么不同方向差这么多

在 3.58 s 的安静高位姿态，拇指、中指与小指的法向力分别约为 0.896、0.512、0.386 N。按三个实际接触的位置和方向，每指法向力上限取当时的测量值，摩擦锥用 16 边近似，并要求球满足力和力矩平衡。所得六轴静态附加力范围在 0.31～0.65 N 之间。世界 −Z 为 0.31 N，+Z 为 0.54 N。本项只解释固定姿态下的方向差异，动态扰动下是否保持抓取见完整复跑。[接触力、方向与静力结果](evidence/static_directions.json)

## 改材料摩擦的对照

只改球和手部接触的滑动摩擦。球桌滑动摩擦始终为 0.45，球桌滚动、扭转摩擦也保持相同。模型中手部 50 个皮肤几何体使用同一组接触常数。修改球侧的材料优先级并复制原有接触参数，运行中核对实际球手与球桌系数。用新实现设回 0.30 后，在两组斜推和一组原侧推上，完整 44 列时序逐元素完全一致。

## 复跑

从干净副本开始，先按[圆柱复跑说明](../seven-axis-control-c4/README.md)创建 Python 3.11 环境。在 Windows PowerShell 的仓库根目录执行以下命令，构建触觉读出库，再复查摩擦系数 0.45 下的一组成功侧推和一组掉球。Linux 将解释器路径换成 `.venv/cylinder/bin/python`。

```powershell
& ./.venv/cylinder/Scripts/python.exe studies/seven-axis-ball-c7/study.py --build --cases push_y3 --modes window6
& ./.venv/cylinder/Scripts/python.exe studies/ball-side-c9/batch.py verify45 --params studies/ball-side-c9/friction_45.json --workers 1 --cases v_side_h oblique_1_1
```

以下四条在上述环境中运行。将 python 指向该环境的解释器，即可复现同一套 24 组独立方向测试。每个输出目录都有控制指令、实际姿态、接触与首次触桌评分。原始记录在本工作副本 `outputs/ball-c9/` 下。

```powershell
python studies/ball-side-c9/batch.py blindA --params studies/ball-side-c9/frozen.json --suite blind
python studies/ball-side-c9/batch.py mu45 --params studies/ball-side-c9/friction_45.json --suite blind
python studies/ball-side-c9/batch.py mu60 --params studies/ball-side-c9/friction_60.json --suite blind
python studies/ball-side-c9/batch.py mu90 --params studies/ball-side-c9/friction_90.json --suite blind
```

把 `--suite blind` 切到 `original`、`expanded` 或 `directions` 可运行原 14 组、扩展 20 组或 26 方向 × 3 阶段。每次切换套件建议使用不同的输出文件夹名。材料数值均为仿真假设。木材相对木材滑动的教材示例约为 0.3，可以用来理解量级。实际橡胶与球之间的摩擦需按材料、表面和载荷确认。[OpenStax 摩擦示例](https://openstax.org/books/college-physics/pages/5-1-friction) · [MuJoCo 接触参数组合规则](https://mujoco.readthedocs.io/en/3.3.7/modeling.html#contact-parameters)
