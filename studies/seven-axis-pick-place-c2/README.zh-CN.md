# 七轴仿生手臂的桌面抓取与放回

C2 将 R8.11 机械手接入七轴手臂的动力学控制。演示采用实际求解的物体和关节状态。两种物体都从桌面取，质量均为 33 g。

| 任务 | 肘角 | 保持时物底离桌 | 保持时物体相对手掌最大单轴变化 | 最终落点误差 |
| --- | --- | --- | --- | --- |
| Ø40 mm 球 | 45° → 100° | 228.9 mm | 0.36 mm | 7.7 mm |
| Ø40 × 170 mm 直立圆柱 | 0° → 100° | 297.9 mm | 0.49 mm | 3.5 mm |

圆柱以小指在下、拇指在上的姿态侧握，放在距离起点约 329 mm 的另一标记处。球回到原取位附近，放回时软指面触桌峰值为 2.76 N。落桌、松手与撤离后，物体均由桌面独立支承。

## 在已经配置好的本机运行

双击 HTML 阅读报告。视频可以在播放器中打开。在本目录打开 PowerShell。建议先从完整压缩包解压到可写目录。复跑会写入新的名义结果并生成新的 ROS 记录目录。

~~~powershell
.\一键复跑.ps1 -Mode ros
.\一键复跑.ps1 -Mode physics
~~~

第一条调用真实 ROS 2 节点，第二条使用相同控制律直接运行物理模型。两者都依次复跑球和圆柱。已有环境时无需启动 SolidWorks。桌面模型沿用本项目的碰撞几何与执行机构参数，由单文件 MJCF 加本目录的 JSON 完整定义。

## 在新 Windows 电脑复跑

使用 64 位 Python 3.11、可执行 C++17 的 MinGW-w64 g++。激活新建的 Python 环境后，安装 `python -m pip install -r requirements.txt`。将 g++ 放入 PATH 或设置 CXX。本仓库不分发 MuJoCo 或 ROS 运行时。

~~~powershell
python reproduce.py
python reproduce.py --task ball --shift-x-mm 3
python reproduce.py --elbow-max-deg 80
~~~

第一条自动编译缺失的步进库并运行两项任务。第三条应返回非零状态，说明用户设定的肘角上限已阻止 100° 任务。运行 ROS 2 需要 Pixi；在 PATH 提供 pixi，设置 ARM_SOLVER_PYTHON 为安装上述三个 Python 包的解释器绝对路径，再运行一键复跑脚本。Windows Jazzy 的依赖来自 RoboStack。rosbag 推荐使用可写本地路径，可用 ARM_ROSBAG_TMP 指定临时目录。500 Hz 为仿真时间的控制频率。

## 复算数据的入口

- `reproduce.py` 复算名义任务。输出包含七轴误差、峰值力矩、五路近端绳力、落桌速度和最终状态。
- `commission.py` 生成 38 组验收记录，`compare_laws.py` 生成 42 组同条件比较，`retry_recovery.py` 运行两次暂态卡滞与解除后的重抓。它们采用进程内控制，ROS 传输验证针对两项名义任务。
- `joint_acceptance.py` 验证七轴逐轴运动和用户限制。`ros_driver.py`、`ros_worker.py` 是规划、反馈控制和物理求解的 ROS 入口。
- `settings.json` 含轴序、机械范围和初始手指参数。`recipe_ball.json` 和 `recipe_cylinder.json` 包含起抓位置、收绳时序和放置标定。joint_trajectory 中的单位为 rad、rad/s，手指收绳命令为 m。
- 两个 ROS 核验 JSON 列出每个话题的回读数量及对应 bag 名称。私有技术包另存 SQLite3 原始记录、原始 NPZ 状态和对照结果。

## 物理与归属

任务位置已知，手臂用编码器跟踪。五路屈指中仅无名指有近端绳力反馈，其余以行程驱动；第六路控制拇指对掌。物体具有自由刚体关节，接触和摩擦承载。球的滚阻、手套接触、惯量、驱动上限、传感延迟和传动效率属于模型假设。本文结果是桌面仿真。软指面在球放回时存在接触，整臂自碰和实物驱动热性能需要独立验证。
